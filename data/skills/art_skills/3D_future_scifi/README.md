# 未来科幻3D风格（Future Sci-Fi）说明

本风格为 toonflow 全新开发的**未来科幻（Future Sci-Fi）**美术风格，将高强度科幻电影质感、硬核高科技设定与东方审美基因做融合，所有美术提示词、规范和生成内容均严格限定于：

- **未来科幻大片质感**：以电影级科幻视觉为内核，融合霓虹都市、星际舰船、太空站、机甲载具、全息界面等未来科技元素，追求宏大、冷峻、神秘、希望的高概念视觉语言。
- **电影级3D渲染**：8K高精度模型、4K超清PBR物理材质、次世代游戏级拓扑、金属/亚克力/全息/碳纤维/玻璃材质拉满，光线追踪、体积光、镜头光晕、全局光照、景深虚化、LUT色彩校准。
- **未来科幻专属色盘**：以深空黑、电光青、冰蓝、银白、荧光紫为主基底，搭配低饱和霓虹点缀（青蓝霓虹、冷紫辉光、白绿全息），杜绝荧光溢色，冷峻克制与科技未来感兼具。
- **东方科幻美学（可选）**：在纯未来科幻基础上，可叠加中式元素（东方骨相、中式纹样再设计、东方对称构图、留白）做国风科幻变体，拒绝无内核元素堆砌。
- **高概念造型语言**：角色为未来战士/舰长/工程师，服饰为机能服+装甲+全息配件；场景为未来都市/星舰内部/太空殖民地；道具为高能武器/能量饰品/科幻载具。

## 适用范围

- 未来科幻题材的AI美术生成（角色立绘、场景概念、道具设计、载具/机甲、分镜脚本、游戏CG、影视海报等）
- 需要电影级3D质感、高强度科幻氛围、霓虹光效与高科技细节的视觉创作
- 未来科幻题材游戏美术、影视概念设计、动画短片、数字藏品等商业应用场景

## 严禁内容

- 写实摄影/真人照片级真实感（除非特别标注）
- 中世纪/古风/修真/西式奇幻/哥特/维多利亚等非科幻内核元素
- 现代都市日常/乡村田园/纯自然风光等无科幻设定场景
- 低精度模型/粗糙拓扑/贴图模糊/穿模/畸形结构
- 过度饱和荧光色/高溢色/强数码噪点/低对比度灰蒙画面
- 违背科幻合理性的物理结构/畸形人体/夸张违和的肢体比例
- 低俗暴露/无科技内核的元素堆砌
