# 人物衍生资产生成 · 未来科幻约束手册

---

## 一、叠加原则

1. **轮廓不变** — 叠加后肢体/装甲轮廓必须与底模完全一致，禁止轮廓偏移
2. **姿态不变** — 保持底模自然站姿，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从同一未来科幻美学体系（冷色 + 霓虹 + PBR）
5. **科技一致** — 叠加装备需符合同一科技设定与文明水平，拒绝穿越式混搭
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「基础妆 / 轻妆 / 正式妆 / 科技妆」强度 |
| L2 | 发型造型 | + 机械发饰 / 全息发丝 / 神经接口 |
| L3 | 内搭/机能底衣 | 替换基础内衬（碳纤维护甲内衬 / 智能纤维） |
| L4 | 外衣/主装甲 | 机动装甲 / 指挥官制服 / 研究员工装 |
| L5 | 配饰 | 全息肩章 / 义眼 / 数据接口 / 机械配饰 |
