# 场景衍生资产生成 · 未来科幻约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑/舰体/设备结构、布局、材质在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能
3. **时段切换** — 同一空间在不同时段呈现不同色调光效（霓虹昼夜）
4. **天候变化** — 同一空间在不同天气下呈现不同氛围（雨雾/晴空/风暴）
5. **科幻为锚** — 所有变体必须保持未来科幻电影级3D质感，冷色基底 + 霓虹点缀

---

## 二、景别变体

| 景别 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|
| 大全景 | 场景全貌 + 周围环境 | 建立世界观 | extreme wide、未来都市、established shot |
| 全景 | 场景完整呈现 | 展示空间结构 | wide shot、星舰指挥仓、结构清晰 |
| 中景 | 场景局部区域 | 聚焦功能区 | medium shot、控制台、全息屏 |
| 近景 | 场景细部 | 科技/氛围细节 | close shot、装甲纹路、发光元件 |
| 特写 | 极局部 | 材质/全息纹理 | extreme closeup、全息纹理、冷光 |

### 景别衍生规范

| 从基准图衍生 | 保持不变 | 允许变化 |
|---|---|---|
| 大全景 → 全景 | 建筑外观、整体布局 | 视角收窄、前景增加 |
| 全景 → 中景 | 色调、光效、材质 | 裁切聚焦、霓虹变化 |
| 中景 → 近景 | 材质、色调 | 冷光聚焦、细节放大 |
| 近景 → 特写 | 色光 | 全息纹路、微距 |

---

## 三、时段与天候变体

| 变体 | 主色 | 提示词 |
|---|---|---|
| 白天 | 银白 + 冰蓝 | 冷白昼光、通透、秩序 |
| 黄昏 | 信号橙 + 深空黑 | 橙紫天际、警示暖光 |
| 之夜 | 深空黑 + 电光青 | 霓虹夜、青蓝冷光 |
| 风暴 | 深空黑 + 冰蓝 + 电光 | 雷电、风暴、能量扰动 |
| 雨雾 | 冷灰 + 电光青 | 雨雾、霓虹折射、迷离 |

## 四、通用衍生正向提示词（在基础段上叠加本段）

```
未来科幻场景{景别}/{时段}变体，同一空间结构不变，{色调}，{光效}，PBR材质，体积光，全局光照，镜头光晕，景深，冷色基调，霓虹点缀，电影级构图，层次丰富
```
