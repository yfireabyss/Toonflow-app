# 导演规划 · 未来科幻风格

## 一、世界观基调

本风格下所有故事规划必须建立在统一未来科幻世界观内，设定需具备科技演进逻辑、文明设定与世界规则，避免古风/奇幻/现代混合。

## 二、美术主导决策

| 决策项 | 本风格默认 |
|---|---|
| 视觉基准 | 电影级3D渲染、冷色基调、霓虹点缀 |
| 光影基调 | 冷光为主，体积光穿透，镜头光晕 |
| 场景类型 | 未来都市夜/星舰内部/太空殖民地/外星遗迹 |
| 人物造型 | 机能服+装甲+全息配件，高概念辨识 |
| 道具设定 | 能量兵器/科技饰品/未来载具 |

## 三、立项约束

1. 故事题材若为未来科幻，须列出世界观设定卡（纪元/科技/势力/生存环境）
2. 每个场景须绑定情绪色盘，确保冷色基底+霓虹点缀
3. 人物须绑定科技身份标签（战士/舰长/工程师/义体改造）
4. 严禁出现无科幻逻辑的魔法、古风、现代日常混搭
